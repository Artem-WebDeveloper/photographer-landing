# Vera Photographer | Portfolio Landing Page

Pixel-perfect responsive landing page for a photographer's portfolio, built
with vanilla HTML/CSS/JS - no frameworks. Learning project (RS School)
focused on semantic markup, responsive layout and interactive UI built from
scratch.

## Tech stack

HTML5, SCSS, Vanilla JS, Vite

## Features

- Responsive layout (1440px / 768px / 380px breakpoints)
- Burger menu - slide-out navigation with smooth icon-to-cross transformation
- Custom portfolio slider - hover-zone scroll on desktop, swipe on mobile
- FAQ accordion with persisted open state (single-open behavior)
- Booking modal window with background scroll lock
- Smooth scroll-down button in the Hero section
